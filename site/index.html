Compatibility documented for DeepSeek Harness 0.1.1-rc.2. Build requirements: Node.js ^22.19.0 or ≥24.0.0.

A few things to know.

Does this change my Harness installation?＋

The plugin uses Harness’s public extension services. It registers themes and a settings section without modifying Harness source files.

Does choosing a theme here change my app?＋

This page is an interactive color preview. To apply a theme in your own Harness app, install the plugin and choose it in Settings → Design MD themes.

Where do the 74 themes come from?＋

They are generated from a pinned snapshot of VoltAgent’s awesome-design-md collection, with colors normalized into Harness theme tokens. The names identify design inspiration, not official partnerships.

Is it free to use?＋

Yes. This project is open source under the MIT license. See the repository for the license, source attribution, and third-party notices.
