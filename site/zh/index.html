HARNESS＋ THEMES
01

自然融入。

通过 Harness 公开的 Theme Service 注册主题，并在设置中加入专属入口。熟悉的位置，多一种选择。

02

03

使用原生插件管理器安装。无需修改 Harness 源码、替换文件或额外安装浏览器扩展。

03 / 让喜欢成为日常

一条命令，
换一种打开方式。

已经在用 DeepSeek Harness？添加插件，启动 Web 界面，然后选一款你喜欢的主题。

查看安装文档 ↗
1

添加插件

TERMINAL
dsh plugin --profile web add deepseek-harness-design-md-themes

2

启动 Harness

dsh web
3

选择你的主题

打开 Settings → Design MD themes，选中主题卡片。现在，这里更像你的工作区了。

仓库记录的兼容版本：DeepSeek Harness 0.1.1-rc.2。本地构建要求：Node.js ^22.19.0 或 ≥24.0.0。

你可能还想知道。

会修改我的 Harness 安装文件吗？＋

插件使用 Harness 公开的扩展服务注册主题与设置入口，无需修改 Harness 源文件。

在这里选主题，会改变我的应用吗？＋

这里是交互配色预览。要在你的 Harness 中启用主题，请先安装插件，再到 Settings → Design MD themes 中选择。

74 款主题来自哪里？＋

来自 VoltAgent 的 awesome-design-md 固定版本快照，经过归一化后生成 Harness 主题 token。品牌名称仅标识设计灵感，不代表官方合作。

可以免费使用吗？＋

可以。本项目以 MIT 许可证开源。许可证、素材来源及第三方声明均可在 GitHub 仓库中查看。
