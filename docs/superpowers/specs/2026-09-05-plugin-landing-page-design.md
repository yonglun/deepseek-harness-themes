# 插件宣传 Landing Page 设计草案

状态：用户已确认，进入实现。

## 目标与读者

面向 DeepSeek Harness 用户以及对 AI 产品感兴趣的技术读者，用可切换的主题演示解释插件价值，并引导用户安装或访问 GitHub。

品牌标题使用 DeepSeek Harness Themes；安装命令保持真实包名 `deepseek-harness-design-md-themes`。

## 方案选择

推荐交互主题展厅：真实目录驱动的主题演示、完整主题浏览和安装指引，兼顾视觉吸引力与可用性。

备选为纯图文介绍页，制作与加载成本更低，但无法直接体验换色；或动画主导的沉浸展示页，视觉更强，但增加加载、移动端适配和维护成本。

## 视觉方向

- 暖白色画布、近黑正文、陶土色操作按钮，细分隔线与充足留白。
- 首屏采用大标题与大尺寸工作区演示并列的布局，主题色只作用于演示区域。
- 主文案：中文“你的工作区，值得有自己的风格。”；英文“Make your workspace feel like yours.”
- 副文案说明：74 款受 Design MD 启发的主题，通过 DeepSeek Harness 原生插件机制安装。
- 字体使用系统无衬线字体与等宽代码字体，避免外部字体加载依赖。
- 移动端改为纵向排列，演示内容精简；尊重减少动画偏好。

## 页面结构

1. 顶部导航：品牌、主题浏览、插件介绍、安装、语言切换、GitHub。
2. 首屏：主标题、价值说明、浏览主题与安装按钮，以及可切换配色的工作区演示。
3. 精选主题：Claude、Binance、Linear、Airbnb、Spotify、PostHog、Ferrari、Nintendo 2001，使用现有目录中的真实配色。
4. 全部主题：74 款主题卡片，支持名称搜索、浅色/深色筛选；无结果时提供清除筛选操作。
5. 原生集成说明：公开主题服务注册、设置入口集成、所选主题持久化；链接现有 Everything is a Plugin 博客。
6. 安装：复制命令、启动 Harness、进入 Settings → Design MD themes 选择主题。
7. 简短 FAQ 与页脚：兼容范围、网页预览与实际安装的区别、许可证、来源与 GitHub/npm 链接。

## 交互与内容边界

- 点击精选主题或目录卡片，更新同一个演示面板的名称和配色，并显示选中状态。
- 演示明确标记为“交互配色预览”，使用虚构内容，不伪装成已连接的 Harness 实例。
- 选择可保留在当前浏览器中；禁用存储时仍能正常切换。
- 页面按钮只能复制命令和导航，不能直接修改访客的 Harness 设置。
- 复制成功显示反馈；剪贴板不可用时显示可选中的命令供手动复制。
- 搜索与筛选共同作用，显示结果数量，键盘可操作全部控件。
- 不虚构下载量、用户评价或官方背书。
- 展示仓库明确记录的兼容版本，不将其描述为最新版本或保证适配所有版本。
- 保留 MIT 与来源链接，说明品牌名称只用于识别风格来源，不表示品牌合作。

## 文件与数据

- 独立静态页面放在 `site/`，与插件运行时代码分开。
- `site/index.html` 为英文，`site/zh/index.html` 为中文；两种语言使用独立 HTML 文件。
- 样式、浏览器交互与精简主题 JSON 由两个页面共享。
- 主题 JSON 由现有 `src/themes/generated/catalog.ts` 导出名称、ID、分类、色彩模式和预览色值，避免手工复制 74 套数据。
- 页面使用相对资源路径，可在 GitHub Pages 项目子路径下部署。
- 现有宣传图片仅作为只读素材使用，生成脚本不覆写该图片。
- 当前交付包括页面源码、本地预览与验证；公开部署时再按仓库托管配置执行。

## 验收

- 中英文页面内容对应，互相链接，具有独立标题、描述和正确 lang 属性。
- 主题数量与现有目录一致；切换、组合筛选、无结果处理与复制反馈可用。
- 在 320、768、1024、1440 像素视口检查布局，无横向溢出。
- 使用真实浏览器检查控制台、资源加载、交互和键盘焦点，并查看桌面与移动截图。
- 在子路径下验证两种语言的资源和链接；核对安装命令与现有 README 一致。
- 不改变插件发布包入口或运行时逻辑。
